Set it up in Exhibit's own interface

  1. Open Connections & relay from this artifact's menu.
  2. Add a Bearer token connection for https://httpbin.org. HTTPbin accepts a demonstration token such as a random string.
  3. Grant the connection to this artifact. Approve the API origin and allow relay requests.
  4. Reopen this artifact, then check the connection.

No API key goes into this HTML, your saved data, or an agent conversation.

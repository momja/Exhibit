# Capability popover "Manage security settings" link does nothing on mobile

Gallery > artifact card > Sandbox posture popover > "Manage security settings →" does not navigate on mobile (iOS Safari). Tapping it does nothing.

## Cause

Safari does not focus an anchor on tap. Tapping the Manage link blurs the capability trigger with a null `relatedTarget`, and the popover's `focusout` handler in `web/gallery/components.js` treated that as focus leaving the trigger+popover pair and closed it. Closing sets `pointer-events:none`/`visibility:hidden` on the popover before the tap's `click` is dispatched, so the link never receives it.

## Fix

Only close on a `focusout` that names a destination outside the popover. Pointer dismissal remains the outside-click handler's job, which runs after the link has had its click.

## Acceptance

- Tapping "Manage security settings →" in the card popover on iOS navigates to `/artifacts/:id/edit#security-panel`.
- Tabbing out of the popover still closes it; tapping elsewhere still dismisses it.
- Regression test replaying Safari's event order (`web/gallery/components.popover.test.mjs`), run by `TestGalleryPageScriptSuite`.

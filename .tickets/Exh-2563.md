# Block PR merges with duplicate migration numbers

Run the existing migration version collision guard on pull request merge commits and require the check on main, including an up-to-date base so concurrent migration PRs cannot reuse a number.

## Acceptance Criteria

A PR with duplicate SQL migration numbers or a SQL/Go migration collision fails the required check; a valid tree passes; the main worktree stays clean and on main.

# Hosted launch detours through the login page on an expired Clerk token

Clerk __session JWTs live ~60s. A cold launch (PWA reopen) sends the gallery request with an expired cookie, which falls through to the route gate and redirects to /auth/login. That page loads ClerkJS from the Frontend API, refreshes the token, calls /auth/clerk/ready, then redirects back to the gallery, which loads ClerkJS again. Several sequential round trips before the first card. Fix: renew an expired session without the login-page round trip, and measure cold-launch time before and after under mobile throttling.

# Enhance edit navigation and simplify the artifact Library control

Implement the reviewed contextual artifact-editor navigation. Gallery-to-edit returns to the originating library view; artifact-to-edit returns to the running artifact; direct edit links fall back to My library. The editor names the return destination, identifies the artifact, provides an explicit View artifact action, and saves without redirecting. Protect unsaved edits when leaving. In the artifact control pill, replace the back arrow with an icon-only, self-hosted Phosphor squares-four Library link. Keep Edit in the existing action menu. The approved mock is tracked in Exh-xkvj; its final icon choice is superseded by this ticket.

## Design

Use native ES modules, shared Stimulus behavior with template partials, and server-rendered htmx regions as documented. Carry a validated local return destination explicitly, surviving reloads and direct links. Preserve library search, filters, loaded results and scroll position. Use a fixed Library destination in the artifact pill, independent of browser history; its accessible name and tooltip remain My library. Save changes stays in the editor; leaving dirty title, source, security, widget or state edits offers Save and leave, Discard changes, or Keep editing. Preserve optimistic-concurrency checks and explicit origin approval.

## Acceptance Criteria

1. Library → Edit returns to that library view and its search/filter/results/scroll context. 2. Artifact → Edit returns to that artifact, with its title as the destination label. 3. Direct/bookmarked edit links fall back to My library; external or malformed return targets are rejected. 4. View artifact is explicit; Save changes does not navigate and retains subsequent edits/concurrency revisions. 5. Leaving with unsaved edits is guarded, including native browser leave protection; failed/partial saves keep the editor open. 6. The artifact pill has an icon-only ph-squares-four Library link with a readable accessible name and tooltip; Edit remains in its menu. 7. Desktop/phone navigation tests and screenshots cover the revised UI, and main stays clean.

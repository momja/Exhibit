1. **P2 — let a stable native fieldset own the tag panel lock through its htmx refresh.** `web/gallery/tags.js:109–124` snapshots and disables every individual control, then restores them immediately after the mutation. Successful operations dispatch an asynchronous fragment refresh (`:137`, `:161`, `:192–196`), so the old controls become editable before replacement. Holding `/partials/tag-panel` after a successful mutation lets someone start another name/color draft or reopen the old tag data; the arriving `innerHTML` swap destroys that draft. Keeping references to the old controls also makes the lock ineffective across replacement. Minimal design: make the stable `#tags-body` wrapper a borderless fieldset, toggle its `disabled` property once, and keep the transaction locked until its own `htmx:after:swap`/failure handler. Reuse the established event-driven pattern in `share.js:46–60,212–256`; do not create a Promise around htmx. Retain the existing API calls, status/errors and focus selection. This is a concrete lifecycle defect and simplification, not a requirement to move feature requests into Stimulus.

2. **P2 — keep CodeMirror’s editability inside the editor island.** `web/gallery/new.js:145–146` reaches into `.cm-content` and changes `contentEditable`, while `ArtifactEditor.mount` (`web/editor/editor.js:137–174`) still configures an editable CodeMirror state. Find/replace controls are outside the page’s disabling selectors and remain active during ingestion; CodeMirror’s `replaceAll` and undo commands check `state.readOnly`, which this DOM write never changes (installed `@codemirror/search/dist/index.js:953`, `@codemirror/commands/dist/index.js:287`). Thus a pending upload can visibly change its supposedly locked draft, or a failed upload can return a different draft. Minimal design: retain the mounted editor handle and add a narrow island-owned `setReadOnly` operation backed by a `Compartment` containing `EditorState.readOnly` and `EditorView.editable`. Let `lockIngest` call it; keep DOM knowledge and focus forwarding in the island. This applies AGENTS’ “pull complexity downwards” rule to a real invariant; no generic busy controller is needed.
